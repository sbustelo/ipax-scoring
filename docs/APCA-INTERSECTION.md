# IPAX & APCA: Architectural Intersection & Grading

This document outlines the architectural separation of concerns between the APCA contrast algorithm and the IPAX ergonomic scoring system, specifically regarding how extreme contrast (e.g., pure white on pure black) is processed, graded, and penalized.

## 1. The APCA Core Math vs. The APCA Web UI

The official APCA mathematical algorithm (`apca-w3`) strictly returns a continuous lightness contrast value (`Lc`) and, via its lookup tables, a recommended minimum font size. **The algorithm itself does not return semantic grades or penalties for extreme contrast.** A pair of `#FFFFFF` on `#000000` will consistently yield an `Lc` of ~106.

The semantic labels often associated with APCA (e.g., "Body Text", "Small Text Only", "Spot Text") are not generated by the math. They are presentation-layer UI conditionals hardcoded in the SAPC-APCA web tool (e.g., `if (absContrast > 89.7) { return 'SMALL BODY TEXT ONLY'; }`).

A critical misconception arises at the top of the scale: when the APCA UI flags Lc > 105 as "Small Text Only", it is technically expressing a *permission* (the contrast is high enough to support very small text) rather than a programmatic penalty, even though literature warns against using such extreme contrast for large blocks of text due to halation.

## 2. The IPAX Resolution

To prevent ambiguity and architectural coupling, IPAX resolves this by strictly separating normative math from biological ergonomics:

1. **APCA as a Mathematical Baseline:** IPAX consumes the APCA engine solely to extract the raw `Lc` value and the absolute minimum font size. IPAX maps this `Lc` to its base scale but does not rely on APCA's UI conditionals to penalize the color pair.
2. **IPAX Ergonomic Penalties:** The responsibility of penalizing extreme contrast falls entirely on IPAX's core (`ergonomics.js`). Through continuous biological models, IPAX calculates the actual optical scatter (Halation, Macular Glare, Mydriasis).
3. **Final Grading:** If a pair has an `Lc` of 106, the base score might be mathematically high, but the IPAX ergonomic penalties for halation and glare will directly degrade the final score (e.g., dropping it from a Level 6 "Optimal optical comfort" to a Level 5 or lower). 

Therefore, IPAX accurately reports that the combination is legally compliant and has high photometric contrast, but algorithmically flags it as harmful for sustained continuous reading.
