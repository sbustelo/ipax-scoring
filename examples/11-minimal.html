Integration Architecture

This example represents the absolute minimum requirement to integrate IPAX into your application. It bypasses complex UI components to focus strictly on the required cascade:

  • dist-js/: The core mathematical engine. Any IPAX integration must include this entire directory untouched. It has zero external dependencies.
  • js/apca-bridge.js: Dynamically imports the APCA engine via CDN. This decouples IPAX from APCA to prevent AGPL license contamination. If the network fails, IPAX gracefully degrades to WCAG-only mode, disabling advanced perceptual grading but preserving baseline legal compliance.
  • js/ipax-integration-minimal.js: The raw initializer. It boots the orchestrator and returns the numerical data structure. It does not load external dictionaries (unlike ipax-integration.js), meaning it requires no external data/ folder and is impervious to network/CORS issues.
  • js/minimal-app.js: The minimal DOM controller that reads input values and fires the runIpax() function.

Note on Semantics: If your application requires translated strings for scores or penalties (e.g., "Score 3 - Acceptable"), you should use the advanced js/ipax-integration.js initializer instead, which strictly requires copying the data/ directory containing the JSON dictionaries to your project.
